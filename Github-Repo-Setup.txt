LONG DESCRIPTION (for README top / About):
VetTV DirectStream Widget - Xbox Game Bar widget (Win+G) for direct RTMP streaming without OBS.
Built for VetTV Studios creators with custom VetTV ingest as default (rtmp://ingest.vettv.com/live), plus presets for Twitch, YouTube, Facebook, Kick, Rumble, and custom RTMP.

Features:
- One-click Go Live from Game Bar overlay
- RTX NVENC hardware encoding
- 6 resolutions: 720p/1080p/1440p at 30/60fps
- Game audio + Mic mixer
- Live chat overlay widget
- Settings widget
- Branded VH neon icons matching https://vettv-studios.github.io/vettv-handheld-news/
